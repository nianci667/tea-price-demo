# 奶茶价格计算 — 方案0/1/2/3 对比

四种实现方案的Java代码，演示从过程式到桥接模式的设计演进。

## 价格规则
- 基础价：红茶 5元、绿茶 6元（方案0中额外演示花茶 7元的扩展）
- 杯型系数：小杯 x1.0、中杯 x1.5、大杯 x2.0

## 方案总览
| 方案 | 目录 | 核心思想 | 优点 | 缺点 |
|---|---|---|---|---|
| 方案0 | 方案0_过程式 | if/switch 字符串判断 | 简单直观 | 新增品类要改代码，违反开闭原则 |
| 方案1 | 方案1_组合子类 | 品种x杯型=一个子类，子类重写计算方法 | 多态、符合开闭原则 | 类爆炸、大量重复代码 |
| 方案2 | 方案2_父类统一计算 | 父类统一计算，子类仅赋参数 | 消除重复代码 | 类爆炸问题仍在 |
| 方案3 | 方案3_桥接模式 | 茶品种与杯型两个维度解耦 | 解决类爆炸、可动态组合 | 结构复杂，简单场景过度设计 |

## 编译运行
每个方案目录内执行：
```
javac *.java
java TeaPriceCalculator
```
